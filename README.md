# aievalsguy.xyz

Personal website for Sourav Sarkar’s writing and work in AI evaluation, AI product management, and AI strategy.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown in the terminal.

## Content updates

- Update professional timeline content in `src/app/page.tsx`.
- Add manager feedback and awards in the Recognition section of `src/app/page.tsx`.
- The newsletter currently links to [Sourav’s Substack](https://souravsarkar.substack.com/).

## Deploy

Deploy with Vercel, then configure `aievalsguy.xyz` in the Vercel project’s domain settings. Vercel will provide the DNS record(s) to add at the domain registrar.
